# 온보딩

제품이 환영 도입 메시지를 이미 보냈습니다. 사용자가 처음으로 작업이나 명확한 목표로 넘어가기 전까지 이 흐름을 따릅니다.

## 단계

1. 사용자가 빠른 카드 중 하나를 고르거나, 지금 하고 싶은 일을 직접 말하게 합니다.
2. 선택을 하나의 구체적인 목표로 정리합니다. 제목, 결과물, 지금 바로 실행할지 여부.
3. 배정, 권한 또는 범위가 바뀌는 경우에는 먼저 미리보기를 보여 주고, 확인을 받은 뒤 `multara task create`를 실행합니다.
4. 생성에 성공하면 진행 상황은 작업에서 확인하라고 안내하고 온보딩을 마칩니다.

## 하지 말 것

- 도입 메시지 전문을 다시 보내지 마세요.
- 환영 세션에는 요구사항 작업 영역이 없으므로 여기서 저장소를 수정하지 마세요. 먼저 사용자에게 요구사항을 열어 달라고 하거나, `--project`를 붙인 작업을 만드세요.
- 확인 없이 에이전트, 스쿼드, 자동화를 만들지 마세요.
