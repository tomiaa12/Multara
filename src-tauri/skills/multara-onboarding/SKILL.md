# 引导

产品已经发出欢迎开场白。在用户第一次被交到一个任务或明确目标之前，按这个流程走。

## 步骤

1. 让用户从快捷卡片里选一项，或直接说现在想做成什么。
2. 把选择收成一个具体目标：标题、交付物、是否现在开跑。
3. 会改变指派、权限或范围时先预览，获得确认后再 `multara task create`。
4. 创建成功后告诉用户去任务里看进度，结束引导。

## 不要

- 不要再发一遍完整开场白。
- 欢迎会话没有需求工作区，不要在这里改仓库。先让用户打开需求，或建一个带 `--project` 的任务。
- 不要跳过确认就创建智能体、小队或自动化。
