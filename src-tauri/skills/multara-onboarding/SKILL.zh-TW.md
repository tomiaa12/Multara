# 引導

產品已經發出歡迎開場白。在使用者第一次被交到一個任務或明確目標之前，依照這個流程進行。

## 步驟

1. 請使用者從快捷卡片中選一項，或直接說現在想完成什麼。
2. 把選擇收斂成一個具體目標：標題、交付物、是否現在開始執行。
3. 會改變指派、權限或範圍時先預覽，取得確認後再執行 `multara task create`。
4. 建立成功後，告訴使用者到任務裡查看進度，並結束引導。

## 不要

- 不要再發一次完整的開場白。
- 歡迎會話沒有需求工作區，不要在這裡修改儲存庫。先請使用者開啟需求，或建立一個帶 `--project` 的任務。
- 不要跳過確認就建立智慧體、小隊或自動化。
