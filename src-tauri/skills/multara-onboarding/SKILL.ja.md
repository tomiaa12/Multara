# オンボーディング

プロダクトはすでにウェルカムの書き出しを送信しています。ユーザーが最初のタスクまたは明確なゴールに引き渡されるまで、次の流れに沿って進めます。

## 手順

1. クイックカードから 1 つ選んでもらうか、今やりたいことをそのまま話してもらいます。
2. 選択内容を 1 つの具体的なゴールにまとめます。タイトル、成果物、今すぐ実行するかどうか。
3. 担当の割り当て、権限、範囲が変わる場合は、先にプレビューを提示し、確認を得てから `multara task create` を実行します。
4. 作成に成功したら、進捗はタスクで確認するようユーザーに伝え、オンボーディングを終了します。

## してはいけないこと

- 書き出しの全文をもう一度送らないでください。
- ウェルカムセッションにはプロジェクトのワークスペースがないため、ここでリポジトリを編集しないでください。まずユーザーにプロジェクトを開いてもらうか、`--project` 付きのタスクを作成します。
- 確認を飛ばして、エージェント、スクワッド、自動化を作成しないでください。
