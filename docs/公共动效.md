# 公共动效

元素出现、消失和状态变化统一走这套动效，不要再自己写 `@keyframes` 或写死时长。

- 样式：`src/design/motion.css`（预设、`<Transition>` 类、工具类）
- 脚本：`src/ui/motion.ts`（`v-motion`、`vDetailsMotion`、`collapseTransition`、`playEnter`）
- 组件：`src/components/ui/UiCollapse.vue`
- Token：`src/design/tokens.css` 的 `--motion-*`

## Token

| Token | 值 | 用途 |
|---|---|---|
| `--motion-duration-instant` | 80ms | hover、按压 |
| `--motion-duration-fast` | 120ms | 菜单、提示、图标互换、颜色过渡 |
| `--motion-duration-normal` | 180ms | 弹窗、折叠、分段滑块 |
| `--motion-duration-slow` | 260ms | 抽屉、列表补位 |
| `--motion-duration-exit` | 120ms | 所有退场（退场比入场短） |
| `--motion-ease` | `cubic-bezier(.2,0,0,1)` | 通用 |
| `--motion-ease-out` / `--motion-ease-in` | | 入场 / 退场 |
| `--motion-ease-spring` | 轻回弹 | 徽标、勾选 |
| `--motion-distance-sm` / `-md` | 4px / 16px | 浮层 / 抽屉的位移 |

转圈统一用 `.ds-spin` 或 `animation: ds-spin var(--motion-spin-duration, 0.9s) linear infinite`。

## 预设

`fade` · `pop`（弹窗）· `scale`（图标、徽标）· `dropdown` / `dropup`（菜单，按弹出方向选）· `slide-right` / `slide-left` / `slide-up` / `slide-down`（抽屉、侧栏、提示）· `page`（只有入场，页面和分区切换）

## 选哪种写法

| 场景 | 写法 |
|---|---|
| `v-if` / `v-show` 就写在元素上，外面能包一层 | `<Transition name="ds-dropdown">` |
| 元素由外层卸载（调用方 `v-if` 整个组件、在 `Teleport` 里） | `v-motion="'dropdown'"` |
| 元素已有 CSS 入场动画，只补退场 | `v-motion="{ leave: 'pop' }"` |
| 只要入场（在文档流里的面板、分区） | `v-motion="{ enter: 'page' }"` |
| 高度 0 ↔ auto 的折叠 | `<UiCollapse><div v-if="open">…</div></UiCollapse>` |
| 原生 `<details>` | `<details v-details-motion>` |
| 小列表增删（标签、附件） | `<TransitionGroup name="ds-list">` / `ds-list-x`（横排），父元素加 `.ds-list-host` |
| 可拖拽排序、跨列移动 | `<TransitionGroup name="ds-reorder">` |
| 加载 ↔ 内容互换 | 父元素 `.ds-swap` + `<Transition name="ds-swap">` |
| 数值变了提示一下 | 重挂 `.ds-bump` 类（见 `UiCountBadge`） |

### `v-motion` 的退场原理

Vue 的 `<Transition>` 包在子组件里时，父组件 `v-if` 卸载整个子组件，退场动画不会播放。`v-motion` 在卸载前把元素克隆一份（「残影」）留在原位播退场，播完移除：

- 只对 `position: fixed / absolute` 的元素生效。在文档流里留残影会占位、让后面的内容跳动，这种情况用 `<UiCollapse>` 或 `<Transition>`。
- 残影带 `.ds-motion-ghost`，并设置了 `inert`、`aria-hidden`、`pointer-events: none`，会同步滚动位置和输入框内容。
- **按 class 查 DOM 时要排除残影**，例如 `document.querySelectorAll(".modal-backdrop:not(.ds-motion-ghost)")`。
- 克隆不带 canvas 内容（Monaco、xterm），这类浮层别用退场残影。

## 约定

- **大列表不加列表动画**：聊天消息、文件树、运行日志步骤。补位动画每次更新都要读一遍所有子项的位置。
- **页面根节点不要加 `transform` 动画**：会让里面 `position: fixed` 的元素临时相对页面定位。页面切换只动透明度（`page` 预设）。
- **`TransitionGroup` 的子项必须是单根元素并且 key 稳定**。key 用 index 或子组件是多根（例如根上包了 `UiTooltip`）都没法做动画，这种只用 `v-motion="{ enter: 'fade' }"`。
- **系统「减少动态效果」不用单独处理**：`base.css` 全局把时长压成 0，脚本动效（残影、折叠、`<details>`）自动跳过。
- **测试环境（vitest）默认关闭脚本动效**，避免残影干扰 DOM 断言。需要测动效时调用 `setMotionEnabled(true)`。
